# Airalogy Protocols

> This repository has moved into the Airalogy monorepo and is kept only as a historical standalone source.

Official Airalogy Protocol examples now live in [`airalogy/airalogy/examples/protocols`](https://github.com/airalogy/airalogy/tree/main/examples/protocols). Regression-only protocol fixtures live in [`airalogy/airalogy/spec/fixtures/protocols`](https://github.com/airalogy/airalogy/tree/main/spec/fixtures/protocols).

Use the monorepo locations for new issues, pull requests, examples, tests, and documentation updates.

You can preview and fill the AIMD portions on the Airalogy demo examples page:

- <https://airalogy.github.io/airalogy/aimd/demo/#/examples>

You can also browse and access public examples on the Airalogy platform under Airalogy Official Lab -> the Public Protocols project:

- <https://airalogy.com/labs/airalogy/projects/public_protocols>
